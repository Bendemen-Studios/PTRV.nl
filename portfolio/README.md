# Portfoliofoto's

Upload hier de foto's van je 3D-prints en projecten. De website leest deze map automatisch uit en toont alle afbeeldingen in de doorlopende portfolio-slider.

Ondersteunde formaten: `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif` en `.avif`.

Tips:
- Geef bestanden een korte, duidelijke naam, bijvoorbeeld `headset-stand.jpg` of `3ds-houder.png`. Die naam verschijnt als bijschrift.
- Voeg nieuwe foto's gewoon toe aan deze map; je hoeft de HTML niet aan te passen.
- Houd foto's bij voorkeur geoptimaliseerd en niet onnodig groot, zodat de site snel blijft laden.
